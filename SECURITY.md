# Security Policy

## Supported versions

Security fixes are applied to the latest released version on npm (`secure-password-utility`).

## Reporting a vulnerability

Please report security issues privately to the maintainer:

- Primary contact: Michael Oki — `security.oss.dev@pm.me`

Please include:

- Affected version(s)
- A description of the issue and its impact
- Steps to reproduce or a proof of concept
- Any suggested fix

We aim to acknowledge reports promptly and to release a patched version on npm
once a fix is available. Public disclosure should be coordinated with the
maintainer.

This contact is also used for Anthropic OSS Scanner reports.
